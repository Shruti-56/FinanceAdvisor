# FinanceAdvisor

## Project Overview
**FinanceAdvisor** is a mobile application designed to provide financial guidance to users through an AI-powered chatbot. The app uses GPT-3.5 to give personalized advice on budgeting, savings, and investments.

## Features
- AI-powered finance chatbot
- Real-time responses to financial queries
- Daily financial tips and advice
- User-friendly interface for easy navigation
